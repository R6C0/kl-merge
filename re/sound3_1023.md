# Sound pass 3 (2026-10-23)

Owner: "make the maps feel more engaging and lively ... more ambience ... more unique sounds ... more payday music".
Branch `feat/1023-sound3`. Code: `klhook/klmusic.c` (ASSAULT mood), `klhook/klambience.c` (Local + Panic groups), `tools/kl_sound3.py`,
`tools/sound3_1023.ps1` (+ INSTALL / UNDO .bat). Nothing was run live (the game belonged to the lead / another session).

## What it does

1. Payday 2 music by heist PHASE (klmusic.c). Order of a round: CALM (before the alarm) -> ACTION (stinger + action pool, as before)
   -> **ASSAULT** (new, heavier pool, crossfaded in) -> ESCAPE / DOWN as before. There is NO police signal in the hook, so ASSAULT
   fires from three stand-ins, any one is enough, all off unless the ini turns them on:
   - `AssaultAfter=<s>` seconds since the round turned ACTION (patch: 150),
   - `AssaultOnDown=1` a crew record that was not dead at the ACTION baseline now has status 7 (a dead heister, or a traitor swapped to
     a policeman by klbot.c: both mean "the police are engaging"),
   - `AssaultMoney=<$>` the crew gained that much since ACTION began (patch: 0 = off).
   Once triggered it stays until the round ends or the mood leaves ACTION (ESCAPE / DOWN / END win over it). No `Assault=` list, or all
   three triggers 0, means the mood never exists: old behaviour byte for byte. The engine-music maps (`EngineMaps=`: DM09, DM06B, DM03A,
   DM05A) are untouched; the patch adds no key to them.
   Per map the patch gives `Assault=` (3 to 4 heavy PD2 tracks, none repeated from that map's Action) and 1 to 2 more `Calm=` tracks.
   The tracks are the owner's mp3s played in place from the two PD2 folders (nothing is copied).
2. Unique one-shots per map (klambience.c). Two new groups next to Radio / Alarm / Heli / Distant / Siren / Spot:
   - `Local` (the map's own sounds: trains, planes, harbour horns, cranes, workshop, sparks, mopeds, cats, cicadas, computers, bell,
     armoured truck, Havana crashes, Retomoto PA / lift bell / police-car static), From=calm, After=10, Min=25, Max=70, Vol=50.
   - `Panic` (distant screams, Crowd_Panic, English police megaphone), From=action, After=20, Min=40, Max=110, Vol=50.
   Every map has its own Local list (see `LOCAL` in kl_sound3.py): DM01 gets jets + armoured truck + diner kitchen, DM02 cats + bell,
   DM03 office machines, DM06 cicadas + bicycle bells, DM11B Havana crashes + moped horns, DD01 trains, DD02 ship horns + bridge
   metal, DD03 plane idles + hangar, DD05 harbour + cranes, DD08 cranes + workshop, DD09 crickets + cats, Retomoto tower the PA and lift
   bell, Retomoto street skids + horns. F01..F09 mirror DD01..DD09. A group with an empty list is never scheduled.
   145 mp3 (mono 64k, <= 25 s, 4.1 MB) staged as `local\<theme>_N.mp3` and `panic\<theme>_N.mp3`.

## ini keys (new)

[Music] (global or `[Music.<key>]`): `Assault=` list, `AssaultAfter=` s, `AssaultOnDown=` 0/1, `AssaultMoney=` $, `StingerOn=` may now
contain `assault` (a stinger when the mood starts; default unchanged: `action`).
[Ambience] (global or `[Ambience.<key>]`): `Local=`, `Panic=` lists and `LocalVol/After/Min/Max`, `PanicVol/After/Min/Max`, `LocalFrom`,
`PanicFrom` (calm|action|escape|dead) like the other groups. The load-map log line now reads `... / spot N / local N / panic N clips`.

## Install / undo (owner or lead: the script writes into the game folder)

Hook first: `klhook\out_sound3_1023\dinput8.dll` over `<DD>\dinput8.dll` (back the current one up; an older hook just ignores the new
keys). Then `INSTALL sound3 1023.bat` (refuses while kl2.exe runs, md5-checks the copy, saves `KLHook.ini.before-sound3` once, replaces
the sections). `UNDO sound3 1023.bat` puts those 56 sections back from the saved copy (other edits to the ini stay) and deletes
`KLExpansion\Ambience\local` and `\panic`. Tested on a copy of the installed ini: install twice, then undo gives a byte-identical file.
Order with other passes: independent files (a new ambience subfolder and ini sections). If another pass changed one of these 56
sections after the patch was made, run `kl_sound3.py ini` again first (it re-reads the installed ini).

## GUESS list

- The ASSAULT trigger stand-ins (150 s, record status 7, money) are guesses about when "the police engage"; there is no police signal.
- `Fly_xx / Flyimpact_xx` under Effects/M11_A (Havana "m11" theme) are taken to be crash / fly-by effects; named by path only.
- Which maps get which Local theme is from the bank each clip lives in and the map's setting (e.g. clips present in DD03's bank = airport);
  cat / cicada / collie / crane clips come from Dead Men or other Dog Days banks. Several maps share a theme (wind, flicker, spark).
- `Calm` extras `26_Blueprints_old`, `44_Donacdum` are assumed to be calm pieces (named by title only); judge by ear.
- Panic uses the same list on every Western map and a short one (screams + crowd) on Retomoto: the Japanese crowd has no clip of its own.
- The Panic group fires from `From=action`, i.e. 20 s after ACTION; with only heisters in the round it may fire when no civilian is near.
- Volumes (Local 50, Panic 50) are by ear on paper, not tuned.

## Live test for the lead (needs the SHIP or TEST hook sound3 + the patch installed; owner not playing)

1. Install as above. `KLHook.ini` `[Music] Log=1` and `[Ambience] Log=1` are already on.
2. For speed set `[Music] AssaultAfter=20` (restore 150 after) and `[Ambience] LocalAfter=2 LocalMin=8 LocalMax=12`.
3. Route: Arcade -> Fragile Alliance -> a stock map (Subway DD01/F01, then Airport F03) and then a Dead Men map (DM02 or DM03), Accept,
   play 3 minutes (the autotest launch options also work: they start F01 = Subway).
4. Log lines (in `<DD>\KLHook.log`):
   - `ambience: map F01: bed ... / local 6 / panic 12 clips` (counts are 0 on the old hook or without the patch),
   - `ambience: Local <train_3.mp3> (map F01, round second N)` every 8-12 s with the short timings; `ambience: Panic ...` after ACTION,
   - `music: map F01: Calm N / Action N / Assault N / Escape N / Down N tracks ... assault after 20 s / on down 1 / money 0`,
   - `music: ACTION <track>`, then `music: ASSAULT trigger on F01 (20 s after ACTION began)`, then `music: ASSAULT <track>`,
   - then ESCAPE / DOWN / END lines as before.
   Proves it: the Assault trigger line, a different track after it, Local lines from files only that map names, no `MCI ... failed`.
5. Control: on DM09 (Retomoto) or DM06B nothing from `music:` appears (engine music) and `Local` lines show the tower files.
6. Undo: `UNDO sound3 1023.bat`, restart, the log shows `local 0 / panic 0` and no Assault.

## Open risks

- Not run live at all: only compiled (0 warnings, SHIP and TEST) and the installer exercised on a copy of the ini.
- The new global [Ambience] Panic list applies to every map including engine-ambience maps; they may already have screams of their own.
- 145 extra mp3 decode lazily via MCI: each Local/Panic fire opens one clip on the worker thread, same cost as Spot/Distant.
- Two Local entries on the same map can play on top of a bed + a radio line: the one-shot slots are shared (4), so a busy moment can
  skip a Local clip; harmless.
